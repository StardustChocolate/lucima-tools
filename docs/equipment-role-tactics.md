# 角色自动配装：抢速与控制用途

适用工程：`lucima-tools-main-new-good`；应用版本保持 **1.3.0**；规则版本 `20261025.3`。

本次核对工程内 226 名角色。原有输出、生存、抗性与文档专属方向保留，新增用途由角色当前技能、技能强化、觉醒和可达的追加技能推导。显示哪些用途随实际养成情况变化，未记录的技能强化按 1 级处理。

## 资料与判断方法

- 工程内 `assets/abyss_battle_static.json`，版本 `ark2-115657`：角色、技能、状态、觉醒、技能强化的原始定义。
- 工程内 `assets/abyss_auto_catalog.json`：与原始技能表校验一致的烧魂技能变化。
- 工程内角色图鉴、用户提供的《按角色自动配装方案》与已有专属用途。
- [Ark Re:Code 社区机制查表](https://zzasqas.github.io/ArkRecodetools/mechanics.html)，读取的资料标记为 2026-10-12，用于交叉核对拉条、退条、控制和冷却机制。
- [原作者新手与配装攻略](https://steamcommunity.com/sharedfiles/filedetails/?id=3560104724)：先手角色先追求速度，再按技能选命中或暴击；多用途角色应提供不同配装方向。

网上资料用于核对思路，具体角色用途由本工程实际技能定义决定。没有将攻略里的面板或某个固定命中数值当成所有角色的毕业线。

## 可选择的用途

| 用途 | 门槛与排序 | 用途说明 |
| --- | --- | --- |
| 最高速度＋百暴 | 暴击率至少 100%；速度 → 输出 → 生命 | 保留望月的先手拉条输出用途；识别玛蒂尔达等暴击触发的队友拉条 |
| 最高速度·拉条提速 | 速度 → 生命 → 防御 | 直接对队友拉条、提速；不强加暴击和状态命中 |
| 最高速度·冷却辅助 | 速度 → 生命 → 防御 | 能直接减少队友技能冷却的辅助用途 |
| 最高速度＋命中 | 满足最低命中；速度 → 命中 → 生命 → 防御 | 推条、降速、沉默、被动封锁、压制、增加冷却、眩晕、睡眠、嘲讽、拘禁、驱散等对敌用途 |
| 高命中＋速度 | 满足最低命中；命中 → 速度 → 生命 → 防御 | 希望提高命中、接受牺牲部分速度时选择 |
| 最高速度·无视抗性 | 速度 → 生存 | 仅根据实际无视抗性效果生成；不扩大到同角色的其他技能 |
| 烧魂抢速·无视抗性 | 速度 → 生存 | 必须烧魂才适用，显示对应技能与消耗；未烧魂时应选择命中用途 |

“最高速度”定义的是排序优先级，其他属性不能以综合评分抵消较低速度。大库存仍采用有计算预算的标准/深度推荐，界面会标记未穷尽；不宣称已经找到整个背包的全局最优组合。

## 命中门槛和交互

命中用途增加“最低状态命中”输入框，范围 0～500%，提供不设最低、50%、100%、150%、200% 快捷按钮。默认 100% 是可修改的筛选条件。0 只取消最低门槛，命中仍参与该用途的次级排序。

状态命中不等于技能自身的效果发生率，不能保证无视免疫、闪避或抵抗。不根据角色技能附带的“命中率提升”直接推断状态命中要求。

每名角色独立保存本轮输入。与用户额外属性范围、套装要求合并时取严格交集，出现冲突会明确提示，不自动放宽门槛。切换用途回到“生成推荐”，保留羁绊、装备来源、深度和额外条件；确认穿上仍由用户主动点击。

“查看用途依据与触发条件”可展开对应技能、具体效果、是否需要命中、基础发生率、暴击触发及烧魂消耗。对己方效果与对敌效果分别判断。

## 已特别核对的例外

- **望月**：队友拉条不需要状态命中；高速百暴属于用户选择的先手输出用途。保留“输出优先”“速度＋输出”。
- **玛蒂尔达**：暴击触发队友拉条，对应百暴抢速方向，不能混成免暴击的普通拉条方向。
- **菈法瑞、格萝妮娅、莉娜、拉娜、新春的莎莉丝特、春光华裳卡丽希、水纪**：根据实际技能与觉醒生成队友拉条/提速用途；同角色的对敌效果可另选命中方向。
- **奈兰希尔**：推条和降速仍需命中；烧魂无视抗性限定在对应技能的驱散效果，不能扩大为所有技能无视抗性。
- **克莱儿、复制体克拉菈、雪江、空**：分别识别冷却增加、沉默、被动封锁、压制、推条和降速，提供抢速与高命中两种方向。
- **天宫咲夜、乌尔德、沐夏吉赛尔**：受击或其他被动事件的拉条不当成可以直接释放的先手拉条。
- **安妮丝朵拉**：被动降低速度收益并依赖队友位置触发，不提供普通“最高速度＋命中”，保留高命中与常规方向并显示提示。
- 隐藏技能仅在能从本角色技能到达时用于判断；递归引用有循环与深度保护。变身、资源、被动、概率等限制保留为用途前提。

## 搜索与验证

候选面板继续使用共用计算，包括当前羁绊、觉醒、常驻被动与实际技能强化；战斗中的临时增益和队友光环不冒充常驻面板。装备来源、角色排除、六件完整性与多角色互斥继续执行。

大库存搜索同时保留抢速候选与高命中/高暴击的必要部件，避免只留下前几件快但无法达标的组合。套装加成按已选件数与剩余部位计算可行性范围，合法的当前穿戴仍作为基线候选。

独立小库存枚举核对速度优先、命中优先、百暴门槛与命中门槛；另覆盖烧魂前提、实际觉醒/强化差异、被动例外、循环引用、羁绊、门槛冲突、每角色独立条件和装备互斥。界面使用离线模拟 API，在 320、390、1280 像素宽度检查。未操作真实游戏账号，未做真机战斗验证。

完整角色审核快照位于 `build/equipment-tactics-review/role-audit.json`。该快照使用六觉醒与未指定强化按 1 级的固定审核条件；运行时按账号内真实角色养成生成用途。
