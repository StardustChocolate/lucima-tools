## 本轮发现并修复的问题

H199 图集中有中文部件名称。Spine 运行库对 Base64 文本 data URI 仅执行 `atob`，没有 UTF-8 解码，导致图集名称与正确解码的骨骼名称不匹配，动态立绘退回静态。软件播放器改为向当前 AssetManager 直接提供已解码图集文本，保留软件缓存和原始媒体文件，不修改媒体运行库。加载结束后恢复下载器方法，避免保留图集文本闭包。

浏览器实测覆盖 H199 的 1440 与 390 宽度：静态 800×1040 加载、动态画面非空并持续变化、动态/静态切换、重复打开不重新下载、断网后静态/动态缓存可用，脚本错误为 0。
